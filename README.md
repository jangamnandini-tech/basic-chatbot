
# 🤖 Task 4: Basic Chatbot

## 📌 Goal
Build a simple rule-based chatbot using Python.

## 📝 Description
This project implements a basic chatbot that interacts with users through predefined responses. The chatbot recognizes simple greetings and messages and responds according to specific rules.

## 🚀 Features
- Accepts user input such as `hello`, `how are you`, and `bye`.
- Provides predefined replies.
- Uses conditional statements to identify user messages.
- Continues the conversation until the user exits.

## 💬 Sample Conversation

```text
Chatbot: Hi! Welcome to the chatbot.
You: hello
Chatbot: Hi!

You: how are you
Chatbot: I'm fine, thanks!

You: bye
Chatbot: Goodbye!
```

## 🛠️ Technologies Used
- Python

## 🧠 Key Concepts Used
- `if-elif-else` statements
- Functions
- Loops
- User input and output

## ▶️ How to Run

1. Install Python on your computer.
2. Clone or download this repository.
3. Open the terminal in the project folder.
4. Run the following command:

```bash
python chatbot.py
```

## 🎯 Learning Outcome
Learn the basics of rule-based chatbot development, conditional logic, loops, and user interaction in Python.
